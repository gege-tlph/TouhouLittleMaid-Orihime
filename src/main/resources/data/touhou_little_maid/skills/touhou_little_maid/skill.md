Touhou Little Maid is a mod about maids, Touhou-inspired combat and items, altar-based progression, support tools, and
many decorative or utility systems.

Use this knowledge skill only for gameplay questions such as getting started, obtaining or taming a maid, altar
crafting, Power points, maid tasks and schedules, backpacks, baubles, favorability, recovery, and other implemented mod
systems. It is reference knowledge, not authoritative live state: use the latest context and `query_game_context` for
current entities, equipment, position, or maid state, and use direct state tools for supported player controls.
